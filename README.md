# Skybound — Flight Simulator

A lightweight, browser-based 2D flight simulator. Fly a Cessna-style aircraft through five checkpoints, then make a gentle landing on the runway.

## Run the game

Open `index.html` in a modern web browser. No installation or build step is required.

## Controls

| Key | Action |
| --- | --- |
| `W` / `↑` | Pitch up |
| `S` / `↓` | Pitch down |
| `A` | Reduce throttle |
| `D` | Increase throttle |
| `Space` | Level the wings |
| `P` | Pause or resume |

You can also adjust the throttle with the on-screen slider. Use the sound button to toggle checkpoint sounds.

## Landing

Fly through all five checkpoint rings, then approach the runway at a safe speed with a gentle descent. Landing before clearing the checkpoints or overshooting the runway ends the flight.

## Files

- `index.html` — Game interface and HUD
- `style.css` — Layout and visual styling
- `game.js` — Flight simulation, controls, and rendering
